# Microservices Test

## Project Overview

This project is a microservices-based application developed using Java and Spring Boot.

## Technologies Used

- Java
- Spring Boot
- Spring Cloud
- Eureka Server
- OpenFeign
- MySQL
- REST API

## Microservices

- Booking Service
- Customer Service
- Driver Service
- Feedback Service
- Payment Service
- Trip Service
- Vehicle Service
- Eureka Server

## Architecture

The application is divided into multiple independent microservices.

Eureka Server is used for service discovery, and OpenFeign is used for communication between microservices.

## Features

- REST APIs
- CRUD operations
- Service discovery using Eureka
- Inter-service communication using OpenFeign
- MySQL database integration

## How to Run

1. Start the Eureka Server.
2. Start the required microservices.
3. Test the REST APIs using Postman.
